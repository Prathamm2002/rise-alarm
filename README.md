# Rise

**Rise is a free, Alarmy-style alarm for iPhone.** It uses real system alarms (AlarmKit), so they ring through Silent mode and Focus. You turn one off by finishing a mission: **Math**, **Memory pattern**, **Shake** or **Type a phrase**.

[**Download the latest Rise.ipa**](https://github.com/Prathamm2002/rise-alarm/releases/latest/download/Rise.ipa) (fixed link, always the newest build; also at `https://github.com/Prathamm2002/rise-alarm/releases/download/latest/Rise.ipa`)

Requires iOS 26 or later.

---

## Features

- Real iOS alarms through AlarmKit: they ring in Silent mode and Focus, on the Lock Screen, even when Rise is closed.
- One-time or repeating alarms (pick days, or use the Weekdays / Weekends / Every day presets), each with an optional label.
- Four missions, chosen per alarm:
  - **Math**: easy, medium or hard problems; 1 to 10 of them. A wrong answer gives you a *new* problem, so guessing does not work.
  - **Memory**: a 3x3 grid flashes a pattern (3 to 8 tiles); repeat it. A wrong tap shows a new pattern.
  - **Shake**: shake the phone 10 to 100 times.
  - **Type a phrase**: type 1 to 3 motivational phrases exactly (capitals and punctuation count; autocorrect is off).
- **Try mission** in the editor to practise without an alarm.
- Dark, minimal design with a "Next alarm in 7h 12m" header.

## How "can't escape" works

1. When the alarm rings, the alert shows **Start Mission**. Tapping it opens Rise straight into the mission.
2. Rise pre-schedules **backup alarms every minute for 10 minutes** after each alarm. They are already set before the alarm rings, so they fire even if Rise is not running.
3. While the mission is on screen, Rise plays its own **looping alarm tone** at full volume (audible in Silent mode) and keeps the screen awake.
4. If you open Rise at any point within about 30 minutes of the alarm without having finished, it **goes straight back into the mission**. You cannot reach the alarm list until you finish.
5. Only finishing the mission cancels the remaining backup alarms. For a repeating alarm, the next day's backups are then set up automatically.

## Honest limitations

- **iOS always gives every alarm a system Stop control** (a slider on iOS 26.1 and later). No app can remove it. Each press silences only *that* alert: the backup alarms keep coming every minute for about 10 minutes, each with Start Mission.
- **Force-quitting Rise does not stop the backup alarms.** Deleting the app, or turning off the Alarms permission for Rise, does.
- Alarm volume follows your system volume setting.
- **If the 7-day free signature expires, Rise will not open and missions cannot run.** Whether already-scheduled alarms still ring after expiry is unknown, so **re-sign before day 7** (see below).
- The Shake mission needs a real device (the simulator has no accelerometer).
- No custom alarm tones: the system alarm uses the default sound, and the in-app tone is generated by Rise.
- Free Apple ID limits: 3 sideloaded apps at a time and 10 App IDs per week.
- iOS limits how many alarms an app can schedule. Each enabled Rise alarm uses up to 11 (the alarm plus 10 backups), so keep it to about **5 enabled alarms**. If the limit is hit, Rise shows a banner.

## Install on iPhone from Windows (Sideloadly)

No Mac is needed.

1. Install **iTunes** and **iCloud** for Windows **from apple.com, not from the Microsoft Store**. Sideloadly needs the Win32 (non-Store) versions. Restart the PC afterwards.
   - iTunes: from https://www.apple.com/itunes/, use the direct 64-bit Windows download, not the "Get it from Microsoft" link.
   - iCloud: search apple.com for "Download iCloud for Windows" and use the direct installer link on Apple's support page, not the Microsoft Store.
2. Install **Sideloadly** from https://sideloadly.io.
3. Download **`Rise.ipa`** from [Releases](https://github.com/Prathamm2002/rise-alarm/releases/latest).
4. Connect the iPhone with a USB cable, unlock it, and tap **Trust this computer** (enter your passcode).
5. Open Sideloadly, drag `Rise.ipa` into it, pick your iPhone, enter an Apple ID (a secondary Apple ID is recommended) and press **Start**. Enter the two-factor code if asked.
6. On the iPhone, go to **Settings → Privacy & Security → Developer Mode** and turn it **On**. The phone restarts; after it does, confirm **Turn On**.
7. Go to **Settings → General → VPN & Device Management**, tap your Apple ID under "Developer App", and choose **Trust**.
8. Open **Rise**.

## First run

1. Tap **Allow** when Rise asks for the **Alarms** permission. If you missed it: **Settings → Rise → Alarms**, or tap **Open Settings** on the banner in Rise.
2. Tap **+**, set a time, pick days, choose a mission, and use **Try mission** to see how it feels.
3. Optional but recommended: set a test alarm for 1 to 2 minutes from now, lock the phone, and check that it rings, that **Start Mission** opens the mission, and that the backups follow if you press Stop.

If tapping Start Mission ever does nothing, just open Rise: it will go straight into the mission.

## Every 7 days: re-sign

Apps signed with a free Apple ID expire after 7 days.

- Re-run Sideloadly with the **same Apple ID** and the same `Rise.ipa` (or a newer one). Re-signing keeps your alarms and settings.
- Or turn on Sideloadly's **auto-refresh**: the PC stays on with the Sideloadly daemon running, on the same Wi-Fi as the iPhone.
- Set a calendar reminder for day 6.

## Building

Rise is built entirely by **GitHub Actions** on a macOS runner; no Mac is needed. Every push to `main`:

1. generates the Xcode project with XcodeGen (`project.yml`),
2. runs the unit tests on an iOS 26 simulator,
3. builds an unsigned Release build for devices,
4. packages `Rise.ipa` and attaches it to the [`latest` release](https://github.com/Prathamm2002/rise-alarm/releases/tag/latest).

The workflow is in `.github/workflows/build.yml`. Code layout:

- `Rise/Alarm`: AlarmKit bridge (the only place that builds AlarmKit configurations), scheduler, backup-alarm logic.
- `Rise/Intents`: the Start Mission and Stop intents attached to the alarm alert.
- `Rise/Missions`: pure mission logic (`Logic/`, unit-tested) and the mission screens (`Views/`).
- `RiseTests`: XCTest unit tests.
